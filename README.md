# Paperly — النسخة الكاملة

هذه النسخة تشمل:
- تسجيل الدخول وإنشاء الحساب وتسجيل الخروج عبر Supabase Auth
- العربية / Français / English مع RTL/LTR
- رفع الوثائق إلى Supabase Storage
- تصنيفات
- تاريخ انتهاء وتنبيهات للوثائق القريبة من الانتهاء والمنتهية
- بحث وتصفية
- فتح الوثيقة
- إنشاء رابط مشاركة مؤقت لمدة ساعة
- حذف الوثائق
- لوحة إحصائيات
- تصميم متجاوب للهاتف والكمبيوتر

## الإعداد مرة واحدة
1. افتح مشروع Paperly في Supabase.
2. افتح SQL Editor.
3. أنشئ Query جديدة.
4. انسخ محتوى `supabase_setup.sql` كاملًا واضغط Run.
5. افتح `index.html` عبر استضافة ويب (مثل Vercel)؛ لا تعتمد على فتح الملف محليًا على الهاتف لأن بعض المتصفحات لا تشغّل JavaScript/طلبات الشبكة من ملف محلي.

## ملاحظة مهمة
المفتاح الموجود في `index.html` هو Publishable Key مخصص للواجهة الأمامية. لا تضع أبدًا Secret/Service Role Key داخل HTML أو JavaScript.

## النشر
ارفع `Paperly-complete.zip` إلى Vercel Drop، أو ارفع محتويات المجلد إلى أي استضافة Static HTTPS.

## البريد
إذا كان تأكيد البريد الإلكتروني مفعّلًا في Supabase، سيحتاج المستخدم إلى تأكيد بريده قبل تسجيل الدخول. إعداد SMTP المخصص مطلوب إذا أردت إرسال البريد للمستخدمين خارج إعدادات التطوير الافتراضية في Supabase.
